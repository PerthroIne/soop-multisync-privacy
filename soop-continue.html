SOOP 이어보기 개인정보처리방침

시행일: 2026년 9월 13일 · 적용 버전: 2.0.2
제공자: PerthroIne · 문의: GitHub Issues

SOOP 이어보기는 SOOP VOD를 임시 재생목록으로 구성·저장·불러와 이어서 시청하고, 시청 완료 후 원래 페이지로 복귀하도록 돕는 비공식 Chrome 확장입니다. 개발자 수집 서버로 시청 정보나 목록을 전송하지 않습니다. 다만 영상 조회 및 사용자가 선택한 계정 재생목록 기능을 위해 SOOP 서비스와 통신합니다.

1. 적용 범위와 처리 목적

이 방침은 SOOP 이어보기에 적용됩니다. 별도 확장인 SOOP MultiSync에는 적용되지 않습니다. 데이터는 연속 영상 확인, 임시 목록 구성·편집·저장·불러오기, 재생·반복 제어 및 원래 페이지 복귀를 위해 처리합니다. 구독·로그인·연령·결제 제한을 우회하지 않으며 LIVE 재생은 지원하지 않습니다.

2. 처리하는 정보와 방법

  • 영상·목록 정보 및 공개 계정 식별자: SOOP API 응답에서 영상 ID·URL·제목·유형·재생시간·방송 시각, 업로더·스트리머의 공개 계정 ID·닉네임, 재생목록 이름·영상·순서를 읽습니다. 연속 영상 대조 및 목록 기능에 사용합니다.
  • 웹 탐색·복귀 정보: 브라우저 탭·탐색 API에서 현재 URL과 탭 이동·출처 관계를 확인합니다. SOOP 목록 페이지의 클릭 대상, 페이지 URL과 스크롤 위치를 세션에 기록해 복귀에 사용합니다. Google Sheets 링크의 중간 리디렉션도 VOD 목적지와 출처를 연결하기 위해 확인합니다. 전체 방문 기록 데이터베이스를 읽는 history 권한은 사용하지 않습니다.
  • 사용자 활동 및 재생 상태: SOOP 플레이어의 재생 위치·종료 여부·볼륨·음소거·배속과 확장 메뉴 조작, 목록 페이지의 클릭·스크롤 상태를 필요한 범위에서 처리합니다. 키 입력 내용을 기록하거나 광고 분석용 행동 이력을 만들지 않습니다.
  • 설정: 자동재생·반복 대상·대기시간·종료 및 복귀 설정을 사용자가 선택한 값으로 보관합니다.
  • 파일: 사용자가 직접 선택한 재생목록 JSON의 영상 정보를 읽습니다. 컴퓨터의 다른 파일을 자동 탐색하지 않습니다. 내보내는 파일에는 형식·버전·내보낸 시각 및 영상 ID·제목·URL·순서가 포함됩니다.
  • 인증 세션: SOOP 계정 목록 조회·저장 요청에는 브라우저가 기존 SOOP 로그인 쿠키를 포함할 수 있습니다. 확장이 비밀번호 입력을 요구하거나 쿠키 값을 별도로 추출·보관·파일로 내보내지는 않습니다.

이메일·실명·건강정보·금융 및 결제정보·위치·개인 메시지를 수집하기 위한 기능은 없습니다. 채팅 내용은 목록 기능의 수집 대상이 아닙니다. 기기 안에서만 처리하는 정보도 위와 같이 공개합니다.

3. SOOP 통신과 계정 저장

영상 정보를 조회하기 위해 api.m.sooplive.com 및 api-channel.sooplive.com과 통신합니다. 추천·재생목록 조회 및 계정 목록 저장에는 stbbs.sooplive.com을 사용합니다. API 요청에는 조회 대상 영상·계정·목록 식별자와 검색 조건 등 기능에 필요한 값이 포함됩니다. 네트워크 통신 과정에서 SOOP에는 일반적인 연결 정보와 계정 요청의 인증 세션이 전달될 수 있습니다.

사용자가 계정 저장을 선택하면 목록 이름·영상 ID·순서·공개 및 퍼가기 설정을 SOOP에 전송하여 새 재생목록을 만듭니다. 기본값은 비공개·퍼가기 비허용입니다. 사용자가 선택한 경우에만 공개 또는 퍼가기를 허용합니다. 기존 계정 목록을 덮어쓰거나 삭제하지 않으며, 실패 시 부분 생성된 목록도 임의로 삭제하지 않습니다.

SOOP에 저장된 정보와 서비스 자체의 데이터 처리는 SOOP의 정책 및 사용자 계정 설정에 따릅니다. 이 확장은 SOOP가 운영하거나 보증하는 공식 제품이 아닙니다.

4. 개발자 전송·공유·판매

확장에는 개발자 수집 서버, 광고 SDK 또는 분석 SDK로 사용자 시청 이력이나 목록을 전송하는 기능이 없습니다. 데이터를 판매하거나 광고 타기팅·사용자 프로파일링·신용평가에 사용하지 않습니다. 위에서 설명한 SOOP 기능 수행 외에 무관한 목적으로 제3자에게 전송하지 않습니다.

사용자가 내보낸 파일을 직접 공유하거나 계정 목록 공개·퍼가기를 허용하면 다른 사람이 해당 목록 정보를 볼 수 있습니다. 공유 여부는 사용자가 선택합니다.

5. 저장 위치·기간과 삭제

  • 설정: 브라우저 확장의 로컬 저장소에 보관하며 설정을 변경하거나 확장을 제거할 때까지 유지됩니다.
  • 임시 목록·출처·스크롤 및 조회 캐시: 확장의 세션 저장소와 메모리에 보관합니다. 관련 탭 종료 시 탭별 정보를 정리합니다. 일부 조회 캐시 및 세션 정보는 브라우저 세션 종료나 확장 재시작 시 제거됩니다. 같은 탭에서 원래 페이지로 복귀하는 것만으로 모든 정보가 즉시 삭제되는 것은 아닙니다.
  • 내보낸 JSON: 사용자가 선택한 다운로드 위치에 남습니다. 확장을 제거해도 삭제되지 않으며 사용자가 파일 관리 도구로 삭제할 수 있습니다.
  • SOOP 계정 목록: SOOP에 보관되며 확장을 제거해도 남습니다. 사용자가 SOOP에서 직접 수정하거나 삭제할 수 있습니다.

확장을 제거하면 브라우저가 확장 전용 저장 데이터를 제거합니다. 개발자 수집 서버에 보관된 시청 이력·목록 사본은 없습니다.

6. 보호 조치와 사용자 선택

SOOP 서비스와의 통신은 HTTPS를 사용합니다. 실행 코드는 모두 확장 패키지에 포함되며 외부 JavaScript·WebAssembly를 받아 실행하지 않습니다. SOOP API에서 받는 JSON은 데이터로 처리합니다.

사용자는 자동재생·반복·종료 복귀를 변경하거나 계정 저장 대신 로컬 파일을 이용할 수 있습니다. 확장을 끄거나 제거하면 확장의 처리를 중단할 수 있습니다. 내보낸 파일에는 비밀번호·쿠키·재생 설정을 넣지 않습니다. JSON 파일 자체를 별도로 암호화하지 않으므로 파일 공유와 보관에 주의하세요.

7. Chrome 웹 스토어 제한적 사용

SOOP 이어보기가 Chrome API 및 웹페이지에서 얻은 정보의 사용은 Chrome 웹 스토어 사용자 데이터 정책과 제한적 사용(Limited Use) 요건을 따릅니다. 정보는 공개된 단일 목적의 사용자 기능 제공에 사용하며 개인화 광고, 판매, 무관한 목적의 전송 또는 허용되지 않은 사람의 열람에 사용하지 않습니다.

8. 문의 및 방침 변경

문의는 GitHub Issues에 제목 앞에 [SOOP 이어보기]를 붙여 등록할 수 있습니다. Issues는 공개되므로 비밀번호·쿠키·토큰·비공개 재생목록이나 개인 정보를 게시하지 마세요. SOOP 계정 데이터 관리·삭제는 SOOP에서도 직접 처리할 수 있습니다.

기능 또는 데이터 처리 방식이 바뀌면 이 페이지의 시행일과 내용을 갱신하며 중요한 변경은 이 페이지 또는 스토어 등록정보로 안내합니다.
