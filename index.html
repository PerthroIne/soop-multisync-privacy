SOOP MultiSync 개인정보처리방침

시행일: 2026년 9월 1일 · 적용 버전: 0.7.0

SOOP MultiSync는 사용자가 함께 시청하는 SOOP 라이브 방송 2~4개의 재생 시각 차이를 기기 안에서 계산하고, 사용자가 동기화를 시작한 경우 안전한 범위에서 재생 속도를 조절하는 Chrome 확장 프로그램입니다. 아래 정보는 이 단일 목적을 제공하기 위해서만 처리되며 개발자 서버로 전송되지 않습니다.

1. 적용 범위

이 방침은 Chrome 웹 스토어에서 제공되는 SOOP MultiSync 확장 프로그램에 적용됩니다. 확장 프로그램은 https://play.sooplive.com/* 페이지와 해당 페이지가 멀티뷰 안에 포함된 프레임에서만 동작합니다.

2. 처리하는 사용자 데이터와 수집 방법

Chrome 웹 스토어 정책상 기기 안에서만 읽고 계산하는 경우도 사용자 데이터 처리에 포함될 수 있으므로, SOOP MultiSync는 다음 항목을 명시적으로 공개합니다.

분류처리 항목수집·처리 방법
웹 탐색 활동현재 열려 있는 play.sooplive.com 방송 페이지 URL, 방송 ID, 탭·프레임 구분값SOOP 방송 페이지에 포함된 확장 프로그램 스크립트가 페이지가 열린 동안 자동으로 읽습니다.
웹사이트 콘텐츠화면에 표시되는 방송 제목, 비디오 재생 위치, 재생 여부, 재생 속도, 버퍼 구간과 준비 상태SOOP 플레이어의 비디오 요소에서 동기화 상태 계산에 필요한 값만 읽습니다.
미디어 시간 메타데이터SOOP 미디어 패킷의 시작 시각과 UTC 시각, Worker의 오디오 시작 시각, fMP4 컨테이너의 트랙 종류·timescale·tfdt 디코드 시각페이지가 이미 수신한 WebSocket·Worker 메시지와 SourceBuffer 입력을 브라우저 메모리에서 관찰하여 시간 숫자와 MP4 헤더만 추출합니다.
사용자 설정 상태동기화 시작·중지 상태, 자동 감지된 개별 탭 또는 멀티뷰 그룹, 계산된 동기 오차와 목표 배속사용자의 팝업 조작과 계산 결과로 생성되며 실행 중 메모리에만 유지됩니다.

SourceBuffer에 추가되는 미디어 조각은 컨테이너 시간 헤더를 찾기 위해 메모리에서 검사되지만, 영상·음성 페이로드를 디코딩하거나 복사·저장·전송하지 않습니다. 채팅 WebSocket은 검사 대상에서 제외하며 채팅 내용, 로그인 정보, 쿠키, 비밀번호, 결제 정보, 위치 정보 및 개인 통신을 수집하지 않습니다.

3. 사용자 데이터 처리 목적

  • 개별 방송 탭과 멀티뷰 안의 방송 플레이어 자동 감지
  • 각 플레이어의 공통 재생 시각 및 상대 동기 오차 계산
  • 사용자가 동기화를 시작한 경우 앞선 방송만 제한적으로 감속
  • 시계 또는 버퍼가 불안정할 때 제어를 중단하고 1.000배속으로 복귀
  • 팝업과 방송 화면에 현재 동기화 상태 표시

처리한 데이터는 광고, 사용자 프로파일링, 신용 평가, 분석·통계, 추적 또는 위 목적과 무관한 용도로 사용하지 않습니다.

4. 저장 위치와 보관 기간

처리 정보와 계산 결과는 사용자의 기기 안에 있는 페이지 메모리 및 Chrome 확장 프로그램 서비스 워커 메모리에서만 일시적으로 유지됩니다. 개발자 또는 제3자가 운영하는 서버, Chrome Storage, Local Storage, IndexedDB 또는 파일에 저장하지 않습니다.

닫히거나 응답이 중단된 방송의 상태는 동작 중인 목록에서 약 15초 이내 제거됩니다. 페이지 새로고침, 탭 닫기, 확장 프로그램 중지·삭제 또는 브라우저의 관련 실행 환경 종료 시 해당 메모리 정보는 더 이상 유지되지 않습니다. 서버에 보관된 사본이 없으므로 별도의 서버 삭제 요청 절차는 필요하지 않습니다.

5. 외부 전송, 공유 및 판매

SOOP MultiSync는 처리 정보를 개발자 서버나 분석·광고 서비스로 전송하지 않으며 제3자에게 공유하거나 판매하지 않습니다. 페이지와 확장 프로그램 사이의 상태 전달은 같은 사용자의 브라우저 내부에서만 이루어집니다.

팝업에서 사용자가 직접 “진단 정보 복사”를 누른 경우, 화면에 표시된 동기화 상태가 사용자의 시스템 클립보드에 복사됩니다. 이는 사용자의 명시적 동작이며 확장 프로그램이 외부로 전송하지 않습니다. 이후 붙여넣기와 공유 여부는 사용자가 결정합니다.

6. 원격 코드 및 제3자 서비스

확장 프로그램이 실행하는 모든 코드는 Chrome 웹 스토어에 제출된 패키지 안에 포함되어 있습니다. 외부 JavaScript, WebAssembly 또는 원격 코드를 다운로드하거나 실행하지 않습니다. SOOP 페이지가 자체적으로 실행하는 플레이어·Worker는 SOOP 서비스의 일부이며, 확장 프로그램은 그 코드의 URL을 가져와 확장 프로그램 코드로 실행하지 않습니다.

SOOP 웹사이트 자체의 데이터 처리는 SOOP의 약관과 개인정보처리방침을 따릅니다. 이 확장 프로그램은 SOOP와 독립적으로 제공되며 SOOP가 운영하거나 보증하는 공식 제품이 아닙니다.

7. 사용자 선택과 통제

동기화 제어는 사용자가 팝업의 시작 버튼을 누른 뒤에만 활성화됩니다. 중지 버튼을 누르면 모든 제어 배속이 1.000배속으로 복귀합니다. 사용자는 확장 프로그램을 끄거나 삭제하여 모든 처리를 중단할 수 있습니다.

8. 보안 및 최소 권한

확장 프로그램은 단일 목적에 필요한 https://play.sooplive.com/* 호스트 접근만 요청합니다. 일반 웹사이트의 방문 기록이나 다른 도메인의 콘텐츠에는 접근하지 않습니다. 처리 데이터는 외부 네트워크로 전송하지 않고 필요한 최근 표본만 제한된 메모리 배열에 유지합니다.

9. Chrome 웹 스토어 제한적 사용 준수

SOOP MultiSync가 Chrome API 및 웹페이지에서 받은 정보의 사용은 Chrome 웹 스토어 사용자 데이터 정책과 제한적 사용(Limited Use) 요건을 준수합니다. 데이터는 공개된 단일 목적 제공에만 사용되며, 개인화 광고·판매·무관한 목적의 전송 또는 허용되지 않은 사람의 열람에 사용되지 않습니다.

SOOP MultiSync's use of information received from Chrome APIs and webpages adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

10. 방침 변경

기능 또는 데이터 처리 방식이 변경되면 이 페이지의 시행일과 내용을 갱신합니다. 중요한 변경은 Chrome 웹 스토어 등록 정보 또는 이 페이지를 통해 안내합니다.

11. 문의

개인정보처리방침 또는 데이터 처리에 관한 문의는 GitHub Issues에서 접수할 수 있습니다.
