SOOP MultiSync 개인정보처리방침

시행일: 2026년 8월 10일

SOOP MultiSync는 SOOP 라이브 방송의 재생 지연을 최소화하고, 사용자가 선택한 방송들의 재생 시점을 조정하는 Chrome 확장 프로그램입니다. 처리되는 정보는 확장 프로그램의 핵심 기능 제공에만 사용됩니다.

1. 처리하는 정보

기능 제공 중 다음 정보가 사용자의 브라우저 안에서 일시적으로 처리될 수 있습니다.

  • 열려 있는 SOOP 방송 탭과 멀티뷰 프레임의 식별 정보
  • SOOP 방송 ID 및 화면에 표시되는 방송 제목
  • 플레이어의 재생 위치, 버퍼 상태, 재생 속도 및 재생 오류 상태
  • SOOP HLS 재생목록 URL, 응답 시각 및 재생목록의 시간 메타데이터

2. 이용 목적

위 정보는 SOOP 방송 감지, 라이브 지연 최소화, 방송 간 CDN 기준 시점 비교, 재생 위치 조정 및 상태 표시를 위해서만 사용됩니다.

3. 저장 및 전송

SOOP MultiSync는 처리한 정보를 개발자가 운영하는 서버로 전송하거나 영구 저장하지 않습니다. 상태 정보는 확장 프로그램이 동작하는 동안 메모리에서만 유지되며, 브라우저 또는 확장 프로그램 실행 환경이 종료되면 제거됩니다. SOOP 서비스 제공에 필요한 요청은 SOOP 서비스 도메인과 직접 이루어집니다.

4. 공유 및 판매

처리한 정보를 제3자에게 판매하지 않으며, 광고·신용 평가 또는 확장 프로그램의 핵심 기능과 무관한 목적으로 공유하거나 사용하지 않습니다.

5. 권한 사용

SOOP 라이브 페이지와 멀티뷰 플레이어를 감지하고, SOOP HLS 응답 시각을 관찰하며, 이미 열려 있는 SOOP 플레이어에 확장 프로그램 패키지에 포함된 스크립트를 적용하기 위해 필요한 범위의 Chrome 권한을 사용합니다. 일반 웹사이트의 방문 기록을 수집하거나 저장하지 않습니다.

6. 정책 변경

기능 또는 데이터 처리 방식이 변경되는 경우 이 페이지를 통해 변경 내용과 시행일을 안내합니다.
